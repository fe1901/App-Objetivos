# Lista de metas

App desktop em Pyside6 para criar listas de metas com prazo.

## Como rodar

Primeiro baixe o arquivo .zip e extraia


Segundo com Python 3.10+:** baixe o código e execute `baixar.bat` (Windows)
ou `./baixar.sh` (Linux/macOS).

Terceiro rode o ListaDeObjetivos

## Recursos

 - Criar, editar e excluir listas e metas
 - Exportar e importar listas por JSON
 - Temas claro/escuro
